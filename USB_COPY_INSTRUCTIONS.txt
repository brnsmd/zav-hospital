TO COPY EVERYTHING TO USB
---------------------------

1. Make sure USB drive is inserted
   (Should appear as /dev/sda1)

2. Run the copy script:

   cd ~/Projects/Zav
   ./copy_to_usb.sh

3. Provide fingerprint/password when asked for sudo

4. Wait for copy to complete (~2-3 minutes)

5. Safely eject USB:

   sudo umount /mnt/usb

6. Unplug USB drive

TROUBLESHOOTING
----------------
USB not detected:
  lsblk -f
  (Look for /dev/sda1 or similar)

Permission denied:
  Make sure you ran with sudo:
  sudo ./copy_to_usb.sh

Script not executable:
  chmod +x copy_to_usb.sh
